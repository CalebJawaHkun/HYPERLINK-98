# 📼 HYPERLINK '98 — 90s Cyberspace Portal & Web OS

> **A high-fidelity love letter to the 1990s Information Superhighway, fused with modern 2026 web responsiveness, 60fps animations, and procedural audio synthesis.**

---

**Author**: Caleb Jawa Hkun  
**Architecture**: React 19 &bull; Tailwind CSS v4 &bull; Vite &bull; Web Audio API &bull; HTML5 Canvas  
**Aesthetic**: Web 1.0 / Windows 95 / GeoCities Cyberpunk with Modern Twists  

---

## 🌟 Overview

**HYPERLINK '98** is an interactive desktop operating system and Web 1.0 cyberspace portal. It reimagines the nostalgic charm, bold bevels, pixel typography, and playful chaos of early web exploration through a snappy, accessible, and responsive modern web application.

---

## 🕹️ Key Features & Applications

### 1. 🌐 Web Explorer '98 (Flagship Cyber Portal)
- **Netscape-style Navigation**: Retro toolbar, address bar, and an authentic `"56K Connect!"` dial-up sound button.
- **Animated Marquee Ticker**: Smooth CSS3-powered ticker cycling 1998 breaking cyberspace headlines.
- **3D Gold Chrome Hero**: Retro 3D headline typography with animated hazard caution stripes and sparkling stars.
- **Live 7-Segment LED Hit Counter**: Real-time visitor counter widget with clickable `+1 Hit!` interaction.
- **Web 1.0 Heritage Badges**: Classic badges (*"Netscape 4.0 Gold"*, *"Made with Notepad"*, *"Y2K Compliant"*, *"CyberCafe Certified"*).
- **Interactive Webring Navigator**: Discover decentralized web nodes (*Silicon Alley BBS*, *NeoTokyo GeoCities*, *Chiptune Archive*).
- **90s Browser Wars Poll**: Live interactive voting with animated progress bars (Netscape vs. IE4 vs. Mosaic vs. Lynx).
- **Cyberspace Guestbook**: Live signature board with customizable pixel avatars, timestamps, and messages.

### 2. 📻 WinPulse '98 Media Player
- **Winamp-Inspired Skin**: Retro chaser titlebar, track list, volume slider, and LED track time counter.
- **Procedural Chiptune Synthesizer**: Generates 3 multi-track 8-bit/16-bit melodies in real-time (*Cyberspace Drift '98*, *Neon Highway 56k*, *Geocities Under Midnight*).
- **Real-Time Spectrum Visualizer**: Animated canvas equalizer with segmented green/yellow/red LED bars and falling peak lines.

### 3. 👾 Cyber Invaders '98 (Arcade Minigame)
- **Playable Space Shooter**: 8-bit canvas arcade shooter with moving alien fleets, laser collisions, and sound effects.
- **Controls**: Arrow Keys / A-D to navigate, Spacebar to shoot (plus on-screen touch controls for mobile).
- **Scoring & Lives**: Score counter, high-score tracking, and 3-heart life system.

### 4. 💻 BBS Cyber-Terminal (MS-DOS Shell)
- **VT100 Green Phosphor Shell**: Interactive command line with retro prompt (`C:\CYBERSPACE>`).
- **Interactive Commands**:
  - `help` — List all cyber commands
  - `dialup` — Simulate 56k modem handshake audio & connection
  - `matrix` — Toggle falling green digital matrix rain
  - `sysinfo` / `neofetch` — Display 1998 hardware and OS specs
  - `fortune` — Print random 90s web wisdom
  - `theme <name>` — Switch active theme via CLI
  - `secret` — Unlock hidden easter egg
  - `clear` — Clear terminal screen

### 5. 🎨 PixelPaint '98
- **MS Paint-Style Art Studio**: 16-color 90s palette with Pen, Round Brush, Spray Can, and Eraser tools.
- **Adjustable Brush Sizes**: 2px, 4px, 8px, 14px pixel sizes.
- **Export & Clear**: Save your pixel artwork directly as a `.png` file.

### 6. 🗂️ Desktop OS & Window Manager
- **Draggable & Maximizable Windows**: 3D beveled window frames with focus layering (z-index hierarchy), minimize, maximize/restore, and close buttons.
- **Windows 95 Style Taskbar**:
  - **Start Menu**: Launch apps, switch settings, or trigger the iconic `"Shut Down Cyberspace..."` dialog.
  - **Active Window Tabs**: Focus or minimize open windows with one click.
  - **System Tray**: Live digital clock, blinking 56k TX/RX lights, CRT shader toggle, and audio mute switch.

## 🎨 4 Dynamic Retro Themes

Switch themes anytime via the system tray dropdown or terminal:
1. **Windows 95 Classic**: Teal desktop (`#008080`), battleship grey bevels, navy titlebars.
2. **Cyber Geocities Neon**: Obsidian dark mode (`#070814`) with glowing hot magenta and hyper cyan accents.
3. **Mac OS Platinum**: Apple System 7-8 pinstripes, classic platinum chrome, and crisp typography.
4. **Phosphor Green Matrix**: Monochromatic green terminal display with phosphor CRT scanlines.

---

## 🔊 Procedural Audio Engine

All sound effects (snappy mouse clicks, window whooshes, error chords, modem dial tones, laser blasts, explosions, and chiptunes) are synthesized on-the-fly using the browser's **Web Audio API**.
- Zero external MP3/WAV assets required — 100% offline and ultra-fast.
- Master sound toggle with mute status indicator in the bottom taskbar.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm or yarn

### Installation & Run

```bash
# Clone or navigate to the repository
cd 80s_estatics

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

# 90s Web Aesthetics with Modern Twist — Customization Rule

This rule guides all UI/UX design, component creation, and styling in this repository.

## Guiding Principles
- **Aesthetic**: 1990s Web 1.0 (Windows 95/98 OS chrome, Geocities/Cyberpunk, BBS, CRT monitors, pixel fonts, 3D bevels, marquee tickers, visitor counters) blended with modern high-end UX (fluid responsiveness, smooth 60fps animations, Web Audio API sound synthesis, theme toggles, and clean React 19 architecture).
- **Styling**: Tailwind CSS + custom retro utilities (raised & inset beveled borders, CRT scanlines, neon bloom, pixel fonts).
- **Sound**: Procedural retro sound effects with master mute switch.
- **Responsiveness**: Flawless mobile & desktop support.
